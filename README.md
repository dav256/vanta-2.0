> **Current version:** This repository contains the active version of Vanta. The first version remains available at [dav256/vanta](https://github.com/dav256/vanta).

**Vanta is a Discord bot built with Node.js 20 and containerized with Docker.**

Docker keeps the runtime consistent: build the image once, then run the bot from the container commands below.

## run it

```
docker build -t vanta .
docker run vanta
```
